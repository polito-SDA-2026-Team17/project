# Project
The repository for the project of Software Design and Architecture 2026 - Group 17

## Structure:
**This repository contains the following directories:**

1. **images/*** - this directory contains the images used throught the reports

2. **journals/*** - this directory contains the markdown files to be used as journals throught the duration of the project. Each group member has his own respective journal to keep track of the tasks completed.

3. **reports/*** - this directory contains the reports, the output of the project.

4. **templates/*** - this directory contains the templates (snippets of markdown format) to facilitate the coherence of the team's documentation
